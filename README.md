### Step 2: Prepare Claude

You need a working Claude account with the skills feature enabled. If you haven't set this up yet, go to your Claude settings and activate the "Skills" module. This is free and takes less than two minutes.

### Step 3: Install the Skills

1. **Locate Your Skills Folder**: Open your Claude app and navigate to Settings > Skills. Note the folder path displayed there. On Windows, this is usually `C:\Users\[YourName]\AppData\Roaming\Claude\skills`.

2. **Copy the Files**: Extract the downloaded ZIP. You will see a folder named `skill-files`. Copy all the `.md` files from this folder into your Claude skills folder.

3. **Restart Claude**: Close and reopen Claude completely. This ensures it scans and loads all new skill files.

### Step 4: Test Your Installation

Ask Claude a simple security question like: "How do I check if my website has SQL injection vulnerabilities?" If Claude responds using structured, expert-level methodology mentioning techniques like UNION-based attacks or error-based detection, your installation is working perfectly.

## 🔧 Troubleshooting

### Common Issues

**Problem**: Claude doesn't recognize any of the skills
**Solution**: Verify the skill files are direct files in the skills folder, not nested in subfolders. Check file extensions end with `.md`.

**Problem**: Some skills work, others produce generic responses
**Solution**: Update Claude to the latest version. Older versions may not support all skill features.

**Problem**: Getting file access errors during installation
**Solution**: Right-click the skills folder, select "Properties", then "Security". Ensure your username has "Full Control" permissions.
